Workflow design

The point is not "ask AI for ideas." The point is a repeatable system with explicit stages, scoring, and a human gate.

1. NormalizeClean raw language
2. ExtractPain, stakes, objections
3. Expand12 angle families
4. ScoreICP fit, novelty, proof
5. ShipBrief + channel assets

LLM contract

The private AI step is constrained by a fixed schema so the output can be reviewed, ranked, and routed into downstream assets.

{
  "buyer_signal": "...",
  "pain": "...",
  "stakes": "...",
  "objection": "...",
  "angles": [
    {
      "hook": "...",
      "channel": "LinkedIn | email | landing page",
      "proof_needed": "...",
      "cta": "...",
      "score": 0-100
    }
  ],
  "human_review": "required"
}

Why this matters for Wynter

Wynter already owns the hard part: original buyer data. The leverage comes from turning one research finding into many credible, non-generic ways to earn attention from VPs of Product Marketing, then measuring which ones create qualified demos.

Prototype result: one raw signal is converted into 12 angle families and a ranked top five in one pass. This page does not claim business performance because it has not been deployed as a live campaign.

Next production step: connect the schema to a private LLM endpoint, add CRM context, log experiment IDs, and capture demo conversion by angle.
